# Figure Generation Code for NHPABC

This repository contains the code used to generate figures for the paper 
"Multimodal brain cell atlas across the adult macaque lifespan".

## About NHPABC

The Non-Human Primate Aging Brain Cell atlas (NHPABC) is a comprehensive 
multimodal single-cell resource profiling 2,955,873 nuclei from eight brain 
regions of 23 female cynomolgus macaques across the adult lifespan...

## Repository Structure

figures/              → Code for main figures (Figure 1-7)
supplemental_figures/ → Code for supplemental figures (Figure S1-S7)
